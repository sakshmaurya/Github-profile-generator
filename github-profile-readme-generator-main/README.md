#### Tired of editing GitHub Profile README with new features?

This tool provides an easy way to create a GitHub profile readme with the latest add-ons such as `visitors count`, `github stats`, etc.

## 🧐 Features

Just fill in the details such as `Name`, `Tagline`, `Dev Platforms Username`, `Current Work`, `Portfolio`, `Blog`, etc. with a minimal UI.

### Core Features
- **Uniform Dev Icons** - Beautiful, consistent skill icons
- **Uniform Social Icons** - Professional social media links
- **Visitors Counter Badge** - Track profile views
- **GitHub Profile Stats Card** - Display your GitHub statistics
- **GitHub Top Skills** - Showcase your programming languages
- **GitHub Streak Stats** - Show your contribution streak

### 🎨 Customization Features
- **3 Built-in Templates** - Minimal, Professional, and Creative styles
- **7 Color Themes** - Default, Cyberpunk, Minimal, Vibrant, Ocean, Sunset, Forest
- **Custom Skill Addition** - Add your own skills with custom icons
- **Skill Proficiency Levels** - Show beginner, intermediate, or expert level
- **Drag & Drop Section Reordering** - Arrange sections in your preferred order
- **Multiple Profile Management** - Save, load, and switch between different profiles
- **QR Code Generator** - Generate QR codes for your GitHub profile

### Dynamic Content
- **Dynamic Dev(.)to Blogs** (GitHub Action)
- **Dynamic Medium Blogs** (GitHub Action)
- **Dynamic Personal Blogs from RSS Feed** (GitHub Action)
- **Wakatime Stats**
- **Buy Me A Coffee button**

### Preview & Export
- **Real-time Preview** - See changes instantly with GitHub Light/Dark/Dimmed themes
- **Visual Template & Theme Badges** - See selected template and color theme in preview header
- **Markdown Export** - Copy or download your README.md
- **JSON Export/Import** - Save and restore your profile data
- **Push to GitHub** - Directly push generated README to your repository

### Profile Management
- **Auto-Save** - Automatically saves your progress to localStorage
- **Profile Manager** - Save, load, and delete multiple profile configurations
- **Form Persistence** - Never lose your data with automatic saving

### Developer Experience
- **Hydration Optimized** - Fast SSR with client-side hydration fixes
- **Responsive Design** - Works perfectly on mobile, tablet, and desktop
- **Accessibility** - Reduced motion support, keyboard navigation, screen reader friendly

Click on `Generate README` to get your README in `markdown`.
You can preview the README too.
